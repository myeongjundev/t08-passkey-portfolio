## 작업 목표

기존 자기소개 사이트를 모던한 풀스택 개발자 포트폴리오로 개편하고, ALEPH Studio 과제의 완주 체크리스트에 맞는 검증 자료와 제출 문구를 준비했습니다.

## 1. 포트폴리오 디자인 개편

### 정보 구조

- 첫 화면에서 이름, 직무, 핵심 역량과 대표 프로젝트를 바로 파악할 수 있게 재구성했습니다.
- 소개 → 개발 방식 → 대표 프로젝트 → 문제 해결 사례 → 결과 화면 → 연락 순서로 배치했습니다.
- 큰 문서 형태였던 기존 페이지를 프로젝트 중심의 포트폴리오 구조로 변경했습니다.

### 개발자 프로필 강화

- 추상적인 프로젝트 포스터가 개발자보다 편집 디자인처럼 보인다는 문제를 발견했습니다.
- 첫 문장을 `백엔드의 구조를 설계하고, 화면까지 완성합니다.`로 수정했습니다.
- 오른쪽 영역을 코드 편집기 형태의 개발자 프로필 카드로 교체했습니다.
- Java 21, Spring Boot, MySQL, React 19를 첫 화면에 표시했습니다.
- API Design, Web UI, Team Convention을 주요 관심 영역으로 표현했습니다.

### 기술 스택

- Java, Spring Boot, MySQL, React, Vite, JWT, Docker, Git 아이콘을 추가했습니다.
- MyBatis와 OAuth2는 전체 디자인에 맞춘 문자형 아이콘을 사용했습니다.
- 기술 목록에 마우스를 올렸을 때 강조되는 효과를 적용했습니다.

## 2. 콘텐츠 정리

### 대상 문장

이 페이지는 **신입 개발자를 뽑거나 함께 팀을 이룰 사람**에게, 협업 규칙을 세우고 API 설계부터 화면까지 완성하는 힘을 보여주기 위해 만들었습니다.

### 대표 프로젝트

- 프로젝트: CLOV
- 설명: 친구 전용 우정 기록 서비스
- 기간: 2026.06 — 2026.08
- 구성: 4인 팀
- 역할: 팀장 · Full-stack Developer
- 담당: API 설계, 권한 모델, 프런트엔드 화면, 협업 규칙

### 상황·행동·결과 사례 3개

1. API 계약과 DB 스키마를 한곳에서 관리하고 협업 규칙을 제안했습니다.
2. 공간 구성원 여부와 작성자 여부를 분리해 권한을 두 단계로 설계했습니다.
3. 화면에 흩어진 서버 요청을 도메인별 API 모듈로 분리했습니다.

### 공개 근거

- [CLOV Backend](https://github.com/Pickeslog/clov-api)
- [CLOV Frontend](https://github.com/Pickeslog/clov-web)
- 개인정보를 가린 CLOV 결과 화면 4개

## 3. 공개 범위와 상호작용

- 첫 화면에 `공개 범위 확인` 버튼을 추가했습니다.
- 공개·비공개 항목을 모달 창에서 확인할 수 있게 했습니다.
- 마우스 클릭과 키보드 `Enter`, `Space`로 모달을 열 수 있게 했습니다.
- 닫기 버튼, 바깥 영역 클릭, `Esc`로 창을 닫을 수 있습니다.

### 공개 정보

- 이름
- 기술 스택
- 맡은 역할
- 프로젝트 저장소
- 개인정보를 가린 결과 화면

### 비공개 정보

- 전화번호와 이메일
- 얼굴, 생년월일, 상세 주소
- 팀원 이름, 닉네임과 아바타
- 비밀번호, 토큰과 API 키

## 4. 발견하고 수정한 결함

| 결함 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 대상이 불분명함 | 누구에게 보여주는 페이지인지 바로 알기 어려움 | 첫 화면에 대상 문장 추가 |
| 공개 범위가 빠짐 | 새 디자인에서 공개·비공개 정보가 보이지 않음 | 공개 범위 버튼과 점검표 추가 |
| 내용과 연결된 상호작용 부족 | 링크와 스크롤 효과만 존재 | 공개 범위 모달 추가 |
| 기술을 빠르게 구분하기 어려움 | 기술 이름만 나열 | 브랜드 아이콘 추가 |
| 개발자 정체성이 약함 | 편집 디자인과 프로젝트 포스터 느낌이 강함 | 코드 프로필과 주요 기술을 첫 화면에 배치 |
| 배포 후 스타일이 풀림 | 새 HTML과 이전 CSS 캐시가 함께 표시됨 | CSS와 JavaScript 주소에 버전 추가 |
